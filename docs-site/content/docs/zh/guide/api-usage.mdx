# API 使用方法

ChinAI API 通过一个 API Key 同时支持多种 AI 协议。同一个 Key 可以调用 OpenAI 兼容、Anthropic Claude 和 Codex Responses 三种协议。

## 基础地址

```
https://chinaiapi.com
```

## 认证方式

所有请求都需要 API Key，通过 `Authorization` 请求头传递：

```
Authorization: Bearer sk-你的-api-key
```

## OpenAI Chat Completions 协议

标准 OpenAI 兼容的对话补全接口。

### 接口地址

```
POST https://chinaiapi.com/v1/chat/completions
```

### cURL 示例

```bash
curl https://chinaiapi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的-api-key" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [
      {"role": "user", "content": "你好！"}
    ]
  }'
```

### Python (OpenAI SDK)

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://chinaiapi.com/v1",
    api_key="sk-你的-api-key"
)

response = client.chat.completions.create(
    model="deepseek-v4-pro",
    messages=[{"role": "user", "content": "你好！"}]
)
print(response.choices[0].message.content)
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://chinaiapi.com/v1',
  apiKey: 'sk-你的-api-key',
});

const response = await client.chat.completions.create({
  model: 'deepseek-v4-pro',
  messages: [{ role: 'user', content: '你好！' }],
});
console.log(response.choices[0].message.content);
```

## Anthropic Claude Messages 协议

使用 Anthropic Messages API 格式调用 Claude 模型。

### 接口地址

```
POST https://chinaiapi.com/v1/messages
```

### cURL 示例

```bash
curl https://chinaiapi.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk-你的-api-key" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "你好！"}
    ]
  }'
```

### Python (Anthropic SDK)

```python
from anthropic import Anthropic

client = Anthropic(
    base_url="https://chinaiapi.com",
    api_key="sk-你的-api-key"
)

response = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好！"}]
)
print(response.content[0].text)
```

### JavaScript (Anthropic SDK)

```javascript
import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic({
  baseURL: 'https://chinaiapi.com',
  apiKey: 'sk-你的-api-key',
});

const response = await client.messages.create({
  model: 'claude-sonnet-4-20250514',
  max_tokens: 1024,
  messages: [{ role: 'user', content: '你好！' }],
});
console.log(response.content[0].text);
```

## Codex Responses API

使用 OpenAI Responses API 格式，适用于 Codex 相关工具。

### 接口地址

```
POST https://chinaiapi.com/v1/responses
```

### cURL 示例

```bash
curl https://chinaiapi.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的-api-key" \
  -d '{
    "model": "deepseek-v4-pro",
    "input": "用 Python 写一个 Hello World"
  }'
```

### Compact 模式

需要精简响应时使用 `/v1/responses/compact`：

```bash
curl https://chinaiapi.com/v1/responses/compact \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的-api-key" \
  -d '{
    "model": "deepseek-v4-pro",
    "input": "用 Python 写一个 Hello World"
  }'
```

### Python

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://chinaiapi.com/v1",
    api_key="sk-你的-api-key"
)

response = client.responses.create(
    model="deepseek-v4-pro",
    input="用 Python 写一个 Hello World"
)
print(response.output_text)
```

## 常用工具配置一览

| 工具 | 协议 | 配置方式 |
|------|:----:|----------|
| **Claude Code** | Anthropic | 设置环境变量 `ANTHROPIC_BASE_URL=https://chinaiapi.com` 和 `ANTHROPIC_API_KEY=sk-...` |
| **OpenAI SDK** | OpenAI | 设置 `base_url` 为 `https://chinaiapi.com/v1` |
| **Codex CLI** | Codex | 设置 `CODE_BASE_URL=https://chinaiapi.com` 和 `CODE_API_KEY=sk-...` |
| **OpenCode** | OpenAI | 配置 base URL 为 `https://chinaiapi.com/v1` |
| **Cherry Studio** | OpenAI | 添加提供商，API 地址填 `https://chinaiapi.com` |
