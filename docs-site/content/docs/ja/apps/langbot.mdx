## ChinAI APIとの連携

LangBot は、ローカルにデプロイされたChinAI APIと、ChinAI APIを使用して構築されたサードパーティのChinAI APIサービスへの連携をサポートしています。

### 使用方法

1.  ChinAI APIからAPIキーを取得します
    ![获取 API key](/assets/langbot/get_api_key.png)

        ローカルにデプロイされたChinAI APIの場合は、ご自身でAPIアドレスを設定してください（[コンテナネットワーク接続](https://docs.langbot.app/ja/workshop/network-details.html)を参照）。サードパーティのChinAI APIサービスを使用する場合は、ページからアドレスをコピーできます。注意：アドレスの後に`/v1`を追加する必要があります。

2.  LangBotでモデルを追加し、ChinAI APIプロバイダーを選択し、対応するAPIキーとAPIアドレスを入力します
    ![添加 ChinAI API 模型](/assets/langbot/add_newapi_model.png)

3.  パイプラインでモデルを選択します

    ![选择模型](/assets/langbot/select_model.png)

4.  会話デバッグで会話するか、パイプラインにバインドされたボットと会話することで使用できます

    ![对话](/assets/langbot/debug_chat.png)

    ![微信对话](/assets/langbot/wechat.png)

    ボットのデプロイと設定については、[ボットのデプロイ](https://docs.langbot.app/ja/deploy/platforms/readme.html)を参照してください。

### LangBotナレッジベースの使用

LangBot はChinAI APIの埋め込みモデルの使用をサポートしており、これをナレッジベースのベクトルモデルとして利用できます。

1. LangBotで埋め込みモデルを追加し、ChinAI APIプロバイダーを選択します
   ![添加嵌入模型](/assets/langbot/add_embedding_model.png)

2. 新しいナレッジベースを作成する際に埋め込みモデルを選択します
   ![使用嵌入模型](/assets/langbot/use_embedding_model.png)

その他の使用方法については、LangBot公式ドキュメントを参照してください：[https://docs.langbot.app](https://docs.langbot.app/)
